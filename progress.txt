## Codebase Patterns
- Project root is `/mozartdice/`, Next.js app lives in `/mozartdice/app/`
- Source code is in `app/src/` (using `--src-dir` flag)
- App Router pages are at `app/src/app/`
- Run builds/typechecks from `app/` directory: `cd app && npm run build`
- Tailwind v4 is used (uses `@import "tailwindcss"` syntax, not v3 config)
- New lib modules should go in `app/src/lib/`
- New components should go in `app/src/components/[Name]/[Name].tsx`
- All interactive components need `"use client"` directive
- State store: `@/lib/state/useAppStore` (Zustand v5)
- Measure data: `@/lib/mozart/measureData` — getMeasureData(id) returns null for unknowns
- npm cache issue: use `--cache /tmp/npm-cache` flag if permissions fail
